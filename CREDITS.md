# Credits

**Harness is original work: its design, rules, and skills come from the maintainer's own practice, sharpened by the sources below.** Nothing is copied. Each borrowed idea is re-implemented in this repo's own code and words, and tagged where it lands:

```sh
rg "@attribution"   # every influence, at the exact rule, check, or skill it shaped
```

Package READMEs also list the concepts behind their rules (generated by `pnpm catalog`).

## Design and testing

- Kent Beck, ["Augmented Coding: Beyond the Vibes"](https://newsletter.kentbeck.com/p/augmented-coding-beyond-the-vibes): test-first loop with agents, tidy first.
- David Parnas, ["On the Criteria To Be Used in Decomposing Systems into Modules"](https://dl.acm.org/doi/10.1145/361598.361623) · John Ousterhout, _A Philosophy of Software Design_: modules hide decisions, deep modules.
- Gary Bernhardt, ["Boundaries"](https://www.destroyallsoftware.com/talks/boundaries): functional core, imperative shell.
- Sandi Metz, ["The Wrong Abstraction"](https://sandimetz.com/blog/2016/1/20/the-wrong-abstraction) · Mark Seemann, "Interfaces are not abstractions", "Design Smell: Temporal Coupling".
- Alexis King, ["Parse, don't validate"](https://lexi-lambda.github.io/blog/2019/11/05/parse-don-t-validate/) · Scott Wlaschin, "Making illegal states unrepresentable", "Choosing properties for property-based testing".
- Martin Fowler, "ContractTest", "IntegrationTest", "FlagArgument", "Eradicating Non-Determinism in Tests" · J. B. Rainsberger, "Getting Started with Contract Tests" · Vladimir Khorikov, "When to Mock" · Michael Feathers, "Characterization Testing" · Gerard Meszaros, "Test Logic in Production" · Google Testing Blog, "Don't Put Logic in Tests" · Kent C. Dodds, ["Colocation"](https://kentcdodds.com/blog/colocation).
- Research: [ImpossibleBench](https://arxiv.org/abs/2510.20270), [LLM test oracles](https://arxiv.org/abs/2410.21136), [mutation-guided test generation at Meta](https://arxiv.org/abs/2501.12862).
- Tools: [fast-check](https://fast-check.dev/docs/advanced/model-based-testing/) model-based testing, [Stryker](https://stryker-mutator.io/docs/).
