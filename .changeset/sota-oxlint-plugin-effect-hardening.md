Close bypasses in the existing Effect rules against `effect@4.0.0-rc.115`. `no-run-promise-in-runtime`, `no-unscoped-runtime-launch` and `no-floating-effect` know the six `Effect.run*With` runners, and the two boundary rules also report point-free references such as `program.pipe(Effect.runPromise)`. `no-unsafe-effect-body` and `dependencies-first` cover `Effect.fnUntraced` / `fnUntracedEager`; `no-unsafe-effect-body` additionally reports `try` blocks around `yield*` (catch and finally never run for Effect failures) and global timers inside Effect bodies. `no-untyped-try-promise-catch` covers `Effect.try`. `require-tagged-effect-fail` covers `Effect.failSync`, every native Error constructor, and same-file untagged `extends Error` classes. `no-effect-ordie` covers `Layer.orDie` and `Effect.catch` handlers that only `Effect.die` (new `allowedCalls` values `"Layer.orDie"` and `"catchDie"`). `no-catch-all-cause` covers `catchCauseIf`, `catchCauseFilter`, `sandbox` and `Layer.catchCause`, and its message names the v4 `Effect.catch`. `no-ambient-nondeterminism` reports `performance.now()`. Rules that matched the literal `Effect.` / `Layer.` / `Schema.` spelling (`no-untyped-try-promise-catch`, `no-catch-all-cause`, `no-effect-ordie`, `no-unscoped-runtime-launch`, `require-named-effect-fn`, `no-service-option`, `no-schema-any`, `no-raw-json-parse`, `schema-type-adjacent`) now resolve import aliases and ignore local shadows.
