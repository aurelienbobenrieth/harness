# Official tooling first

Load when the consumer uses one of these stacks. Official tool before any Harness equivalent; verify versions against the registry at install time.

| Stack       | Use first                                                                                                                                                                                                                             | Notes                                                                                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Effect      | `@effect/tsgo` (TypeScript 7): tsconfig plugin + `effect-tsgo patch --oxlint`, oxlint `extends` its `recommended` preset; `@effect/vitest`; `AGENTS.md` and `ai-docs/` inside `node_modules/effect`; `Effect-TS/skills`               | Set tsconfig plugin `diagnostics: false` when oxlint reports them (else findings double); match tsgo's pinned oxlint/tsgolint versions.                                                                            |
| Cloudflare  | `wrangler types` (commit output, `wrangler types --check` in CI); `$schema` in `wrangler.jsonc`; `@cloudflare/vite-plugin`; `@cloudflare/vitest-plugin` (replaces `vitest-pool-workers`); Cloudflare MCP servers; `cloudflare/skills` | Never hand-write `Env`.                                                                                                                                                                                            |
| Shopify     | Shopify CLI (`app config validate`, `app function typegen`, `app webhook trigger`); `@shopify/api-codegen-preset`; `@shopify/polaris-types`; Theme Check; `@shopify/dev-mcp`; Shopify AI Toolkit skills                               | **Dev MCP and Toolkit skills send telemetry, including prompts: always disable it** (`DO_NOT_TRACK=1`, or `opt-out` file in the `shopify-ai-toolkit` config dir). Complements `shopify-review`, never replaces it. |
| PlanetScale | `pscale` CLI; PlanetScale MCP (insights-only variant when queries aren't needed); `planetscale/skills`, `planetscale/database-skills`; deploy-request schema lint; Insights                                                           | Behind Hyperdrive: `pg`, `postgres`, or `mysql2`, never `@planetscale/database`.                                                                                                                                   |
| Alchemy     | `alchemy.run/llms.txt`; `alchemy plan` / `drift` before deploy                                                                                                                                                                        | v2 is Effect-based, beta: pin exactly.                                                                                                                                                                             |
| Drizzle     | `drizzle-kit`; `eslint-plugin-drizzle` for `UPDATE`/`DELETE` without `WHERE`                                                                                                                                                          |                                                                                                                                                                                                                    |
