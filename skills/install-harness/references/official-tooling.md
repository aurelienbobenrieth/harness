# Official tooling first

Load when the consumer uses one of these stacks. Install or wire the official tool before any Harness equivalent; Harness only adds what these don't cover. Verify each version against the registry at install time: these move fast.

| Stack       | Use first                                                                                                                                                                                                                                                                             | Notes                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Effect      | `@effect/tsgo` (TypeScript 7): tsconfig plugin + `effect-tsgo patch --oxlint`, oxlint `extends` its `recommended` preset; `@effect/language-service` for TypeScript ≤ 6 · `@effect/vitest` · the `AGENTS.md` and `ai-docs/` shipped inside `node_modules/effect` · `Effect-TS/skills` | Set the tsconfig plugin's `diagnostics: false` when oxlint reports them, or findings double. tsgo pins exact oxlint/tsgolint versions: match them. |
| Cloudflare  | `wrangler types` (commit the output, `wrangler types --check` in CI) · `$schema` in `wrangler.jsonc` · `@cloudflare/vite-plugin` · `@cloudflare/vitest-plugin` (replaces `vitest-pool-workers`) · Cloudflare MCP servers · `cloudflare/skills`                                        | Never hand-write `Env`.                                                                                                                            |
| Shopify     | Shopify CLI (`app config validate`, `app function typegen`, `app webhook trigger`) · `@shopify/api-codegen-preset` · `@shopify/polaris-types` · Theme Check · `@shopify/dev-mcp` · Shopify AI Toolkit skills                                                                          | **Dev MCP and Toolkit skills send telemetry, including prompts.** Tell the user; opt out with `DO_NOT_TRACK=1` unless they accept it.              |
| PlanetScale | `pscale` CLI · PlanetScale MCP (insights-only variant when queries aren't needed) · `planetscale/skills`, `planetscale/database-skills` · deploy-request schema lint · Insights                                                                                                       | Behind Hyperdrive: `pg`, `postgres`, or `mysql2`, never `@planetscale/database`.                                                                   |
| Alchemy     | `alchemy.run/llms.txt` · `alchemy plan` / `drift` before deploy                                                                                                                                                                                                                       | v2 is Effect-based and in beta: pin exactly.                                                                                                       |
| Drizzle     | `drizzle-kit` · `eslint-plugin-drizzle` for `UPDATE`/`DELETE` without `WHERE`                                                                                                                                                                                                         |                                                                                                                                                    |

Official agent skills and MCP servers are installed the same way as Harness skills and added to the task → skill map; never copied into the repo.
